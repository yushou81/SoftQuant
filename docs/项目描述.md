# 项目简介

这是一个为完成软件质量实验的项目。

实验要求：开发一个能够自动分析软件质量的度量工具 。

特点：
1. 自动化
2. 量化指标
3. 工具需要**涵盖课程中的大部分度量原理**，并能针对软件开发**不同阶段**的实体进行度量 。

## 功能需求

`功能需求采用数据流图或用例图描述`

- 面向对象度量 (核心)：必须实现 CK 度量模型（如类之间的耦合度 CBO、继承深度 DIT 等）和 LK 度量模型 。
- 传统度量：必须包含代码行 (LoC) 和圈复杂度 (Cyclomatic Complexity) 的统计 。
- 进阶选项 (可选)：鼓励加入功能点度量、用例度量、特征点度量等 。


## 数据需求
`数据需求采用ER图或UML类图描述`

不能只读代码，指导书要求输入项应当多样化

- 设计阶段图表：包括类图、程序流程图、用例图等 。
- 源代码：直接对程序代码进行分析（建议利用 ASTParser 进行静态分析） 。
- 度量目标：除了代码规模，还要能预测或评估工作量、成本、开发时间及人员 。
